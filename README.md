
# Address Book Application in C

## Overview
The Address Book is a menu-driven application developed using C programming. It allows users to manage contact information, including names, phone numbers, and email addresses.

## Features
- Add new contacts
- Search for contacts
- Edit existing contact details
- Delete contacts
- List all saved contacts
- Store contact information using file handling
- Validate user input

## Technologies Used
- C Programming
- Structures
- Pointers
- Functions
- File Handling
- Makefile
- GCC Compiler

## Compilation
Compile the project using:

```bash
make
```

Alternatively, compile manually:

```bash
gcc main.c contact.c file.c -o addressbook
```

Update the source file names according to your project.

## Execution
Run the application:

```bash
./addressbook
```
